# Task Manager Project

A professional task mangement application with work space , project , and tasks built with Next.js and TypeScript and used feature base folder structure.

# Features
1.**complete Authentication** : Login , Sign up , Forgot Password  
2.**Three Level Structure** : Work Space > Project > Task
3.**Theme and Dark/Light Mode** : Custom color theme with dark/light mode toggle
4.**Powerful Forms** : React hook form + zod validation 
5.**Persian calendar** : Persian (jalali) date picker with date-fns-jalali
6.**State Management** : Redux Toolkit for tasks handling
